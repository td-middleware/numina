$ARGUMENT

## 审查重点

### 1. 注入攻击
- SQL 注入（拼接 SQL 字符串、未使用参数化查询）
- 命令注入（shell_exec、system、exec 等）
- XSS（未转义的用户输入直接输出到 HTML）
- LDAP/XML/JSON 注入

### 2. 认证与授权
- 硬编码的密码或 API Key
- 弱密码策略
- 缺少权限检查
- JWT/Token 验证缺陷

### 3. 敏感数据暴露
- 明文存储密码
- 日志中打印敏感信息
- 不安全的 HTTP 传输

### 4. 依赖安全
- 已知漏洞的第三方库版本
- 不必要的权限请求

## 输出格式

对每个发现的问题，请按以下格式报告：

**[严重程度: 高/中/低]** 问题描述
- 位置：文件名:行号
- 风险：具体风险说明
- 修复建议：如何修复

最后给出整体安全评分（1-10）和优先修复建议。
