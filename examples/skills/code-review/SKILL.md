请对以下代码进行全面的 Code Review：

$ARGUMENT

## Review 维度

### 1. 正确性
- 逻辑错误、边界条件处理
- 错误处理是否完善
- 并发安全（race condition、死锁）

### 2. 性能
- 不必要的循环或重复计算
- 内存分配优化
- 数据库 N+1 查询问题
- 缓存使用是否合理

### 3. 可读性与可维护性
- 命名是否清晰
- 函数/方法是否过长（建议 < 50 行）
- 注释是否充分
- 是否遵循项目代码风格

### 4. 设计
- 是否符合 SOLID 原则
- 是否有过度设计或设计不足
- 接口设计是否合理

## 输出格式

按严重程度分类（🔴 必须修改 / 🟡 建议修改 / 🟢 可选优化），每条包含：
- 问题描述
- 代码位置
- 改进建议（附代码示例）
